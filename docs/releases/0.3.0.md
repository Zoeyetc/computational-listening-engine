# Computational Listening Engine 0.3.0

Version 0.3.0 changes the internal LIVE rolling architecture. Melody acoustic observation is now incremental and anchored to the listening session. Temporal Melody interpretation remains fully revisable across the bounded history, and Bass continues to derive from each newly interpreted Melody evidence timeline.

FILE and other full-buffer analysis behavior is unchanged. Existing runtime exports remain unchanged and the rolling implementation remains internal. Rolling sessions add an optional passive `onDiagnostic` observation callback, with public record and sink types, so development consumers can measure the built-in production path without replacing its analyzer.

On the deterministic Engine benchmark, the production rolling update measured approximately 114.00 ms median versus 506.96 ms for the previous full-snapshot baseline on the same fixture, an approximately 77% reduction in Engine rolling-update runtime. This is an Engine benchmark, not an end-to-end microphone-to-screen latency measurement.
