# Computational Listening Engine 0.4.0

Version 0.4.0 adds Drum Evidence v1 as an **experimental, uncalibrated** public type contract. It is an additive inspection surface for the Engine's existing deterministic Percussion analysis; existing Percussion events and other listening domains remain available through their established APIs.

`ListeningMap.drumEvidence` distinguishes unavailable analysis, no percussive opportunity, and observed interpretation attempts. Observed attempts distinguish named selection, deliberate abstention, and rejection, with explicit reasons. When class scoring occurred, the evidence exposes the five existing named hypotheses—kick, snare, closed-hat, open-hat, and tom—as ranked comparative heuristic scores. `other-percussion` remains an ambiguity fallback rather than a calibrated sixth class.

Physical event strength remains separate from classifier evidence. Comparative scores, margins, transient quality, consistency, and `uncalibratedConfidence` are bounded heuristic diagnostics. They are not probabilities, likelihoods, accuracy estimates, or certainty percentages.

FILE analysis produces Drum Evidence from the existing Percussion pass without a second classifier or duplicated FFT/transient analysis. Rolling/LIVE analysis exposes the same evidence as a bounded snapshot in session time; the existing rolling event stream retains its publication deduplication and Drum Evidence does not add a temporal Drum solver.

This release does **not** tune the classifier, thresholds, gates, class weights, refractory policy, or rolling cadence. It does not improve or claim Drum onset detection, classification accuracy, confidence calibration, source separation, or arbitrary polyphonic Drum tracking. Known real-audio limitations include Kick/Tom confusion, weak Snare and Hi-hat correspondence in the evaluated material, conservative sustained-event rejection, and difficulty with mixed audio.

The package-root runtime export set is unchanged. Drum Evidence adds public TypeScript types and the optional `ListeningMap.drumEvidence` field. Internal evidence builders, classifier implementation, profiling tools, Gate A and counterfactual research tools, reports, fixtures, and tests are not public package entry points.
