# Computational Listening Engine 0.3.1

Version 0.3.1 is a correctness and rolling-runtime robustness patch.

Generated Melody pitches that are non-finite or not strictly positive are now rejected before pitch-range classification or evidence retention. Malformed rejected pitch evidence cannot enter compact Melody evidence, and Melody-to-Bass adaptation independently excludes invalid frequencies and values that cannot produce finite MIDI pitches. `solveBassPath` remains strict and unchanged.

Failed background rolling analyses are now contained instead of surfacing as unhandled Promise rejections. A failed run publishes neither an update nor a success diagnostic, while `analyzeNow()` continues to reject explicitly when its analysis fails.

The deterministic reproduction is fixed in Node and Chrome. It represents the invalid YIN interpolation mechanism and is not claimed to reproduce the unavailable original Safari microphone PCM. No valid-input listening behavior changes were observed, and this release makes no performance claim.
